# Security policy

- Run the tool locally on a system you own or are authorized to assess.
- Review the source before running it, especially when using `sudo`.
- The program is designed to be read-only, apart from writing its own local reports.
- Reports are private by default. **Never commit actual system reports** to a public repository without review.
- Report security issues privately to the repository maintainer via GitHub private vulnerability reporting if enabled.
- Do not include passwords, tokens, `shadow` contents or other secrets in issues or pull requests.
- This tool is not a penetration-testing framework or a certified compliance auditor.
